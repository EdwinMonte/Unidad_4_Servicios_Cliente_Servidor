# Unidad 4 · Servicios cliente/servidor

Laboratorio con Ubuntu Server 26.04.1 LTS, Fedora Server 45 y el segmento VMware U4_LAB.

| Tarea | Servicios y evidencias | Documento |
|---|---|---|
| 4.1 | Kea DHCP, reserva por MAC y BIND9 | [Memoria técnica](Unidad_4/Tarea_4.1/docs/Memoria_Tarea_4_1.pdf) |
| 4.2 | HTTPS con Nginx, PHP y MariaDB. FTPS y SFTP con chroot | [Reporte técnico](Unidad_4/Tarea_4.2/docs/Reporte_Tarea_4_2.pdf) |
| 4.3 | Postfix, Dovecot LMTP e IMAPS con TLS | [Reporte técnico](Unidad_4/Tarea_4.3/docs/Reporte_Tarea_4_3.pdf) |

La secuencia de instalación es 4.1, 4.2 y 4.3. Cada carpeta contiene configuraciones,
scripts y evidencias. La 4.3 agrega SPF a la zona DNS creada en 4.1 y reutiliza la CA de 4.2.
Las pruebas se limitan al dominio empresa.test y a la red de laboratorio 10.44.0.0/24.

Los videos demostrativos se prepararán después. No se incluyen contraseñas ni llaves privadas.
